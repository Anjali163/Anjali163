## 🎯 Featured Projects

### 🚄 **Railway Accident Prevention System (RAPS)**
> *Safety-critical IoT system for railway hazard detection and prevention*

**Tech Stack:** ESP32 • Arduino Uno • FreeRTOS • LiDAR • Ultrasonic • IR Sensors • Cloud Integration

- **Real-time multitasking** using FreeRTOS task scheduler with dual-core ESP32
- **Sensor fusion** across LiDAR, ultrasonic, and IR for robust obstacle detection
- **UART-based communication** with Arduino Uno for relay control and actuation
- **Cloud integration** for real-time alerts and data logging
- **Low-power optimization** with sleep modes and interrupt-driven event handling

**Impact:** Safety-critical prototype demonstrating embedded systems principles in real-world railway safety domain.

---

### 💾 **SPI-Based Accelerometer Driver (HAL_SPI_ACCLE_BM)**
> *Bare-metal and HAL-based driver for LIS3DSH accelerometer over SPI*

**Tech Stack:** STM32F407 Discovery • SPI Protocol • HAL Drivers • UART Debug • Embedded C

- **HAL SPI initialization** with proper clock and mode configuration
- **LIS3DSH register-level programming** for sensor data acquisition
- **Real-time threshold-based LED control** with GPIO interrupt handling
- **UART debug output** for sensor calibration and validation
- **Hardware debugging** of GPIO timing and SPI signal integrity

**Outcome:** Production-ready accelerometer driver with full debugging capability and documentation.
